# Duoop UI MCP

Official Duoop UI component search and complete JSX/CSS source retrieval for Codex, maintained by Duoop UI. No account, API key, browser or network required at runtime.

After installing this package, register its executable:

```sh
codex mcp add duoop-ui -- duoop-ui-mcp
```

Tools: `search_components` finds components, categories, families and gallery variants; `get_component_source` returns a complete runnable source bundle with dependencies and license notices. Optional `file` selects a single manifest path. Both tools are read-only.

Ask Codex: “Find a Duoop UI button with a loading state, show me the variants, then get its complete source.”

For repository installation, configuration, examples, troubleshooting and release instructions, read the [MCP guide](https://github.com/gus-rlin/Duoop-UI/blob/main/docs/mcp.md).

Codex is an OpenAI product. This integration is maintained by Duoop UI.
